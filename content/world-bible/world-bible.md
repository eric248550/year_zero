# 《元年》世界觀設定（World Bible）

> 給設計者和 AI 事件產生器的正典參考。世界的「狀態」以模擬引擎為準；世界的
> 「語氣與設定」以這份文件為準。這裡沒寫到的事情代表尚未決定，不代表禁止。
>
> 所有給玩家看的文字一律使用台灣繁體中文與全形標點。id、旗標、標籤與
> `{{佔位符}}` 維持英文原樣。

## 0. 主軸：文明的復甦

這個遊戲講的是**人類怎麼從一座地堡重新長出文明**。所有故事線、事件和玩家的
選擇，最後都匯流到這條主線上：活下去只是起點，重建才是目的。

文明分成五個階段。每個階段由幾個里程碑組成，里程碑直接讀取世界的狀態
（科技、聚落、人口、劇情旗標），所以玩家永遠看得到「現在走到哪、還差什麼」。

| 階段 | 主題 | 里程碑 |
| --- | --- | --- |
| 1 求生 | 防爆門打開，在地表站穩 | 公共衛生 · 種子與水耕 · 第一個地表聚落 |
| 2 扎根 | 種得出糧食，做得出工具 | 第一次地表收成（`food.surface_farming`）· 灌溉農田 · 工坊 · 第一間教室（`culture.school`）· 人口 140 |
| 3 連結 | 聚落不再各自求生 | 第一支商隊（`trade.caravan`）· 三個聚落 · 聚落營建 · 短波無線電 · 醫療站 |
| 4 秩序 | 人多了，需要規矩和學問 | 居民大會（`governance.assembly`）· 學校 · 抗生素 · 交易路線 · 人口 200 |
| 5 復甦 | 燈光回來了 | 第一個有燈的夜晚（`power.first_light`）· 電網 · 研究所 · 公民憲章 · 人口 300 |

全部完成之後是「新黎明」：地堡檔案裡的知識都已找回，接下來的路沒有人寫過。
一個世界走完五個階段，大約要一百年，也就是好幾代人。模擬的中位數：求生約第 6
年、扎根約第 30 年、連結約第 47 年、秩序約第 73 年、復甦約第 106 年。議會從第 3
年起就會主動派人去建第一個地表聚落（不等地堡變擠）。玩家的角色會死去，
但他們留下的學校、道路和憲章不會。

重建的故事線：

- **重新點亮**：太陽能板 → 第一個有燈的夜晚 → 電網。
- **第一所學校**：沒上過學的孩子 → 抄寫檔案 → 長者的傳授。
- **聚落之間的路**：無線電裡的人聲 → 第一支商隊 → 修一條路。
- **第一部憲章**：誰來定規矩 → 庫存糾紛 → 簽署憲章。
- **重建糧食生產**、**第一次水危機**：見既有故事線。
- **被遺忘的地堡**：真相支線。崩潰的原因會改變人們願意信任誰，但它不是主線。

寫重建事件時：

- 讓每個里程碑都有一個「人」的時刻：不是「解鎖太陽能」，而是「有人爬上屋頂」。
- 公共的大事（成立大會、組商隊、簽憲章）用 `participation: "everyone"`，讓
  每個玩家都能表態；個人的參與（代一堂課、裝太陽能板）寫成個人事件。
- 重建都有代價：物資、風險、或是有人不同意。不要讓進步是免費的。
- 事件標上 `rebuild` 標籤，並放進對應故事線的 `storylineIds`。

## 1. 崩潰（2089 年）

2089 年，一項多國聯合的平流層氣候干預計畫失敗了。短短幾個月內，季風系統
停擺、糧食產區接連歉收，電力、物流與通訊連鎖崩壞，這個地區的每一個政府都
倒了。倖存者知道崩潰帶來的「後果」，但幾乎沒有人知道它的「原因」。

**隱藏真相（祕密 `project_halcyon`）：** 那項干預就是**海爾西恩計畫**，一個
倉促上線的氣溶膠降溫計畫，並被發起它的各國政府刻意掩蓋。這個真相只能在
遊戲過程中被揭露。

## 2. 深港地堡（第七號避難所）

位於舊卡爾德水壩下方的密封地堡。崩潰時約有 300 人住在這裡；四十多年的封閉
生活之後，還剩下大約 120 人：老人記得舊世界，孩子從沒見過天空。**2131 年（tick 0）**，倖存者永久打開了防爆門。

- 濾水機還能讓水流動，但它們是為密封的地堡設計的。
- 種植室的收成單調又脆弱。
- 檔案室保存著現代科學的片段，卻沒有能使用它們的工業。

**隱藏真相（祕密 `founders_pact`）：** 深港地堡的創建者都是海爾西恩計畫的
工程師。他們早就知道計畫可能失敗，才建造了這座地堡。

## 3. 地表

可以住人，但滿目瘡痍：灰燼土壤、有毒的滲水、沙塵暴、毀壞的城鎮。

| 地點 | 開局已知 | 說明 |
| --- | --- | --- |
| 灰淺渡口（Ashford Crossing） | 是 | 緩流河畔的橋鎮，有肥沃的氾濫平原。可建立聚落。 |
| 燼原（Cinder Flats） | 是 | 燒毀的物流園區，廢料豐富。可建立聚落。 |
| 舊水庫（Old Reservoir） | 否 | 乾涸的水庫，底下有乾淨的含水層。可建立聚落。 |
| 青谷（Greenhollow） | 否 | 隱蔽的山谷，有野生果園。可建立聚落。 |
| 種子庫遺址（Seed Vault Ruins） | 否 | 農業研究站，可能還保存著能發芽的種子。 |
| 訊號塔（Signal Tower） | 否 | 哈洛山脊上的中繼塔。 |
| 第十二號避難所（Vault 12） | 隱藏 | 一座不在任何深港地堡地圖上的地堡。只有劇情事件能揭露它。 |

**隱藏真相（祕密 `vault12_fate`）：** 第十二號避難所在一場熱病爆發時自我封閉；
居民選擇隔離，而不是把疫病傳出去。

## 4. 人與職業

- **科學家**：保存並重建知識。
- **工程師**：拆解回收、建造、維修。
- **醫護**：在沒有現代醫療的世界裡讓人活下去。
- **斥候**：走在地表上，覓食，找回失落的東西。
- **農人**：讓種植架和受污染的土地長出食物。

孩子在 16 歲選擇職業。長者（65 歲以上）只有一半的工作能力，但保有記憶。
倖存者務實、帶著傷痕，並且對宏大的計畫抱持懷疑。

## 4.5 衝突：聚落可以滅亡，世界不會

聚落之間不是一家人。每兩個聚落之間有一個**緊張度**（0～100）：

- **會升高**：前哨站年年要人養、一邊吃飽一邊挨餓、一邊擠爆一邊有空位卻不收人、
  地堡人和地表人過不同的日子（有交易路線之前）、拒絕援助、搶奪、分裂。
- **會降低**：時間、短波無線電、交易路線、公民憲章，以及和解的選擇。
- **後果**：緊張度 50 以上，議會不再援助對方；60 以上，比較窮的一方可能去搶
  （缺糧時更可能），有時會死人。
- **分裂**：人多（40 人以上）又擠、或士氣低落的聚落，可能有一群人出走，去建自己
  的聚落或投奔別處；出走的人和原本的聚落結下心結。玩家角色不會被帶走。

事件可以用 `tension` 條件（目標聚落和它的「對頭」之間的緊張度）和
`CHANGE_TENSION` 效果，文字裡用 `{{rival}}` 代表那個對頭聚落。

**兩種活法**（派系，各一次、所有人表態）：
- 地堡派／地表派：`society.surface_first` 讓議會更早派人去地表，地堡士氣略降；
  `society.bunker_first` 讓地堡士氣上升、較晚開拓，地表的人覺得被拋下。
- 開門派／關門派：`society.open_gates` 讓流浪者更常來；`society.closed_gates`
  讓流浪者少來、士氣略升。

## 4.6 時間與會留下來的東西

**季節。** 世界一年結算一次，但一年有四季。事件可以用 `SCHEDULE_EVENT`
安排「幾季之後」的後續（只會被排程觸發的事件標 `scheduledOnly`），同一批人
會回來演完下半場；列在 `away` 的人在那段時間不在聚落裡，不能參與別的事件，
也不做工（但照樣吃飯）。例如：播種之後兩季才收成、去種子庫要大半年、陪人
去搜刮要一季。

**設施。** 穀倉、水井、診所、鍛爐、校舍、圍牆、瞭望塔、溫室、議事廳。每座
有 0～100 的狀況，每年要 1 份物資維護，沒有就壞得很快；低於 30 就沒有作用，
直到修好。有些科技完成時，會在做出它的聚落蓋起對應的設施（公共衛生→水井、
醫療站→診所、工坊→鍛爐、學校→校舍、公民憲章→議事廳……）。搶奪會先打壞
圍牆，沒有圍牆就打壞其他設施。

**法律。** 每個聚落自己的規矩，通常由投票決定、也能投票廢除：配給制、義務
勞動、公倉制、宵禁。各有好處與代價。

**據點。** 聚落可以佔有已發現、沒人住的地點（種子庫、訊號塔、空著的水庫和
廢墟），每年拿到它的產出；別的聚落會眼紅，緊張度慢慢升高，也可能要求讓出。

**專長。** 嫁接、鍛造、配線、接生、考據、認路。學會的人做本行專案時出力多
50%，接生和認路另有好處。帶頭完成專案的人會學到那一行的專長；12～22 歲的
孩子有機會從父母或照顧他的人身上學會。

**跨世代。** 一個人死去時，他最深的交情與恩怨（±40 以上）會以一半的強度傳給
孩子。在搶奪中被殺的人，孩子會記得是誰帶頭的。

## 5. 語氣

懷抱希望，但不天真。重建緩慢而且代價高昂。每一次收穫都有代價；每一場危機
都可能撐過去，也可能撐不過去。不要寫殭屍、變種人、魔法或超級武器。真正的
危險是匱乏、疾病、天氣、廢墟，以及彼此。

## 6. 科技樹與專案

科技分成六條分支，每條四層。每條分支由一種職業推動，分支之間互相需要：

| 分支 | 推動的職業 | 第 1 層 → 第 4 層 |
| --- | --- | --- |
| 農業 | 農人 | 種子與水耕 → 灌溉農田（+水力）→ 作物育種（+學校）→ 大規模農業（+機械製造） |
| 材料與工業 | 工程師 | 回收工具 → 工坊（+資料保存）→ 冶金（+機械動力）→ 機械製造（+學徒制） |
| 能源與基礎建設 | 工程師 | 水力 → 機械動力（+工坊）→ 局部電力 → 電網（+冶金） |
| 醫療與人口 | 醫護 | 公共衛生 → 醫療站（+學徒制）→ 抗生素（+資料保存）→ 婦幼照護（+灌溉農田） |
| 知識與教育 | 科學家 | 資料保存 → 學徒制 → 學校（+聚落營建）→ 研究所（+局部電力） |
| 探索與社會 | 斥候 | 探路 → 聚落營建（+回收工具）→ 交易路線（+工坊）→ 公民憲章（+學徒制，人口 ≥ 150） |

另外還有短波無線電（探路 + 工坊）。

**科技不是研究出來的，是做出來的。** 每一項科技都是一個「專案」：

- 議會、NPC 或玩家在某個聚落發起專案，由一個人帶頭。議會大約每 40 人多開一個
  （最多 5 個），會挑還沒人碰的分支和較早的層級。
- 那個聚落裡該分支職業的居民每年會自動投入；玩家只要「加入」一次，之後每年
  自動出力。做自己職業的專案出力最多。
- 做專案要花知識（科學家產出），開工要花物資。缺糧缺水的年份，進度會慢很多。
- 進行中會出錯（倒退一截）、也會有人突破（往前跳）；沒人做的專案幾年後會被擱置。
- 完成時，帶頭的人和參與的人都會在人生紀錄裡留下一筆。
- **只能發起自己本行的專案**（工程師可以發起工業和能源，其他職業各一條）。
  任何人都可以加入任何專案。
- **帶頭的人決定做法**：穩健、謹慎（慢 15%，很少出錯）、大膽（快 25%，出錯
  兩倍半、更容易突破）、節省（少花三分之一知識，慢 10%）。議會依方針選做法。
- 參與專案的玩家會遇到自己職業的決定：農人決定怎麼試種、工程師決定用新料還是
  舊料、科學家決定照檔案做還是重新驗證、醫護決定新療法先給誰試、斥候決定去哪裡
  找材料。

事件絕對不能假設一項尚未解鎖的科技已經存在。請用 `technology` 前置條件來
限制它們。

## 7. 事件作者規則（人類或 AI）

1. 事件描述的是「可能性」。只有在前置條件成立時才會觸發。
2. 世界狀態**只能**透過型別化的效果改變（ADJUST_RESOURCE、
   CHANGE_RELATIONSHIP、DISCOVER_LOCATION、UNLOCK_TECHNOLOGY、
   CHANGE_SETTLEMENT_STAT、ADD_WORLD_FLAG、REMOVE_WORLD_FLAG、
   CREATE_HISTORICAL_EVENT、REVEAL_SECRET、ADD_LIFE_EVENT、CHARACTER_DEATH）。
3. 祕密只能用 `REVEAL_SECRET` 揭露，絕不能靠寫入旗標。
4. 死去的角色不能參與事件。角色由活著的居民擔任。
5. 歷史只能追加。沒有任何東西能改寫已經發生的事。
6. 資源變動要合乎比例：20 人的聚落每年大約消耗 20 份食物和 20 份水。
7. 盡量讓選項有真正的取捨，並標上它所代表的價值（`cautious`、`bold`、
   `growth`、`science`、`community`、`industry`、`secrecy`、`openness`），
   讓模擬出來的角色能依照個性做選擇。
8. 這是多人遊戲：每個參與者各自做決定。需要每個人分別決定的事件（例如要不要
   一起去探索），請使用 `participation: "everyone"`，並把個人結果放在
   `memberEffects`（角色 `actor` 代表做這個選擇的人）。
9. 只發生在單一玩家身上的事件（人際、生病、被邀去搜刮等），請放一個
   `player: true` 的角色（通常叫 `you`），並加上標籤 `personal`。新世界會依
   每位玩家各自安排這類事件，`chance` 代表相對權重，`cooldown` 以玩家為單位。
10. **集體決定要用投票。** 所有人表態、而且選項會改變整個世界（設旗標、決定
    派系、要不要報復）的事件，必須加上 `"resolution": "vote"`：先收集每個人的
    選擇，再統計一次，只執行勝出的選項（玩家的意見多算 3 票，代表他說動身邊的
    人）。輸的一方的 `memberEffects` 仍然照他自己的選擇套用。沒有設 vote 的
    「所有人表態」事件，每一組會各做各的，所以驗證器不允許它的多個選項去改旗標。
11. **東西要有來處。** 食物、水、物資只能來自勞動（多做一班、搶收）、荒野
    （搜刮廢墟、覓食、找到的倉庫），或另一個聚落。跟別的聚落交易、搶奪、過路費
    一律用 `EXCHANGE`（只會拿到對方真的有的量）。收成類事件要先有田、有種子、
    有時間長（例如 `settlement_age`、`technology`、農人角色）。
12. **科技只能做出來。** 不要用 `UNLOCK_TECHNOLOGY`。事件可以讓一個進行中的專案
    前進或倒退：`CHANGE_PROJECT`（`tech` 指定科技，或 `role` 指定某人正在做的
    專案），條件 `project` 可以判斷某項科技有沒有人在做。
16. **需要時間的事，每個選項都要花時間。** 出遠門的選項用 `AFTER`（幾季後的結果、
    誰外出、風險）或 `SCHEDULE_EVENT`；不要讓「快速版」當場拿到遠方的東西。報酬寫在
    回來的那一刻；去的人死在途中，系統會記下「沒有回來」，不發報酬。設施的好處要
    靠當地蓋起來（`facility` 條件），不要只看科技；修理用帶 `seasons` 的
    `BUILD_FACILITY`。治理用 `flag_any` 同時接受不同的治理方式。
15. **角色要真的存在。** 「朋友」用 `bondWith`（例如 `{"role": "you", "min": 10}`），
    「記得門打開以前的事」用 `bornBefore`，跟孩子有關的事件用 `children` 條件，
    跟土地有關的（播種、挖井）用 `site_feature`。施工用 `BUILD_FACILITY` 的
    `seasons`，蓋好之前沒有作用。互斥的結果（派系、治理方式）列在
    `EXCLUSIVE_FLAGS`，設定一個會清掉另一個。`pnpm content:validate` 會檢查整批
    內容：沒人排程的後續、沒人設定的旗標、設了卻沒人讀的旗標。
14. **讓選擇留下痕跡。** 優先使用會持續存在的結果，而不是一次性的數值：蓋或
    毀一座設施（`BUILD_FACILITY`、`CHANGE_FACILITY`）、立或廢一條法律
    （`ENACT_LAW`、`REPEAL_LAW`）、佔或讓一個據點（`CLAIM_SITE`、`CEDE_CLAIM`）、
    讓人學會專長（`ADD_SPECIALTY`）。條件可以讀 `facility`、`law`、`claims`、
    `site_claimed`；角色可以要求 `specialty`。需要時間的事用 `SCHEDULE_EVENT`。
13. **職業要有自己的決定。** 給玩家的職業事件用 `onProject`（可指定分支）和
    `profession` 限定角色，文字用 `{{project}}` 代表他手上的專案，選項應該是
    真正的取捨：快但危險、慢但穩、花資源換進度，並可用 `approach` 改變專案的
    做法（steady 穩健、careful 謹慎、bold 大膽、frugal 節省）。
